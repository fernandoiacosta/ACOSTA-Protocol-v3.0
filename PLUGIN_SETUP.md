# ACOSTA v3 — installation and compatibility

This repository now includes a portable `SKILL.md` instruction entry point. It is **not** a registered ChatGPT marketplace plugin, hosted API, or executable MCP server.

## Use in skill-compatible AI agents
Install the repository's `SKILL.md` in your agent's supported skills directory, or configure your agent to load it as a skill. Host-specific installation paths vary. Invoke it by name: `acosta-protocol-v3`.

## Use with any other AI
Provide the URL to `SKILL.md` to an agent with repository/web-reading access and ask it to follow the instructions, subject to its system policies. A model with no external skills or retrieval support cannot load the skill automatically.

## Use in a custom GPT or other platform
Create a custom instruction/knowledge integration pointing to `SKILL.md` and the historical roadmap. Platform-specific publication and permission steps are required.

## Verification smoke test
Ask: "Using ACOSTA Protocol v3, plan a multilingual customer-support pilot. Separate evidence from assumptions and provide success metrics." Verify that the answer includes objectives, workstreams, risks, metrics, and no unsupported quantum claims.
